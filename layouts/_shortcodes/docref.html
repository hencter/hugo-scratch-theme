{{- /* docref — a link to the upstream Hugo documentation, in the READER'S language. {{< docref "content-management/front-matter/" >}} {{< docref "functions/css/" title="CSS functions" >}} {{< docref "configuration/output-formats/" zh="configuration/output-formats/" >}} The whole point is that ONE call serves both language twins. The shortcode resolves the host from the current language, so a reader on the Chinese page gets hugozh.cn and the same reader, after switching language, gets gohugo.io — the reference follows the language without the content being edited twice. Hosts come from the site config, not from hard-coded strings: [docs] default = 'https://gohugo.io/' [docs.hosts] zh-cn = 'https://hugozh.cn/' Path compatibility is measured, not assumed: 26 of 26 sampled documentation paths returned 200 on BOTH hosts (see the verification section of the repository's AGENTS.md). Where a path ever diverges, the per-language override keeps the call single: {{< docref "some/new/path/" zh="some/older/path/" >}} # .Get "zh" wins for zh-cn The link carries `hreflang` and `lang` naming the TARGET language, and the host is printed next to the title, because "reference" means different things on the two sites: a community translation vs the upstream original. */ -}} {{- $path := .Get "href" | default (.Get 0) -}} {{- if not $path -}} {{- errorf "shortcode `docref` needs a documentation path (%s)" .Position -}} {{- end -}} {{- /* Per-language override: `.Get` is keyed by the BASE language tag, so "zh-cn" looks up `zh` and "en" looks up `en`. Hyphenated keys are avoided because a shortcode parameter name with a hyphen is not reliably parsed. */ -}} {{- $base := index (split site.Language.Lang "-") 0 -}} {{- with .Get $base }}{{ $path = . }}{{ end -}} {{- $docs := site.Params.docs | default dict -}} {{- $hosts := index $docs "hosts" | default dict -}} {{- $host := index $hosts site.Language.Lang | default (index $docs "default") | default "https://gohugo.io/" -}} {{- $url := $path -}} {{- if not (strings.HasPrefix $path "http") -}} {{- $url = printf "%s/%s" (strings.TrimSuffix "/" $host) (strings.TrimPrefix "/" $path) -}} {{- end -}} {{- $title := .Get "title" -}} {{- if not $title -}} {{- $title = $path | strings.TrimSuffix "/" | path.Base | humanize -}} {{- end -}} {{- $hostName := $host | strings.TrimPrefix "https://" | strings.TrimPrefix "http://" | strings.TrimSuffix "/" -}} {{- $locale := site.Language.Locale -}}
{{ T "reference" }} {{ $title }} {{ $hostName }}
