Two things the built-in version cannot do that a real site needs: · resolve the image through the SAME helper the render hook and the Open Graph tags use, so a page-resource image works in all three places; · emit `loading="lazy"` and `decoding="async"`, and pass through the intrinsic width/height that Hugo read from the file — which is what stops the layout from jumping while the image loads. {{< figure src="photo.jpg" alt="A photo" caption="Taken in 2026" class="figure--right" >}} */ -}} {{- $src := .Get "src" -}} {{- $alt := .Get "alt" -}} {{- $caption := .Get "caption" -}} {{- $class := .Get "class" -}} {{- $link := .Get "link" -}} {{- $maxWidth := .Get "width" -}} {{- if not $src -}} {{- errorf "shortcode `figure` needs a src (%s)" .Position -}} {{- end -}} {{- $image := partial "resolve-image.html" (dict "page" .Page "src" $src) -}}
