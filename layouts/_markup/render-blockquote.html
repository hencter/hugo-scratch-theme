{{- /* render-blockquote.html — every blockquote goes through here. Two behaviours: · a GitHub-style alert (`> [!NOTE]`, `> [!WARNING]`, `> [!IMPORTANT]`, `> [!TIP]`, `> [!CAUTION]`) is turned into a callout, reusing exactly the same partial as the {{< note >}} shortcode, so prose and shortcode callouts can never drift apart visually; · an ordinary quote is passed through unchanged. The alert vocabulary has five values but only four callout styles, so the mapping is explicit — `T "important"` would otherwise be a missing translation. The icon map is a variable rather than an inline pipeline: `dict … | index $type` reverses the arguments, so `index` would receive the map as its collection and the type string as its key. */ -}} {{- $alert := .AlertType -}} {{- if $alert -}} {{- $styles := dict "note" "note" "tip" "tip" "important" "warning" "warning" "warning" "caution" "danger" -}} {{- $icons := dict "note" "info" "tip" "lightbulb" "warning" "alert" "danger" "shield" -}} {{- $type := index $styles (lower $alert) | default "note" -}} {{- $title := .AlertTitle | default (T $type) -}}

{{- partial "icon.html" (index $icons $type | default "info") -}} {{ $title }}

{{ .Text }}
{{- else -}}
{{ .Text }}
{{- end -}}
