{{- /* lang-switcher.html — language links that never 404, in ONE control. For every language site, prefer the translation of the CURRENT page; when the page has no translation in that language, fall back to that language's home page. Linking to a non-existent translation is the most common multilingual defect, and it is invisible in a two-language demo where every page is translated. Two shapes, and in both of them the header holds one control rather than one per language: · exactly two languages — there is nothing to choose *between*, so the control simply IS the other language: one link labelled with its own name. No menu, no second button, one click to switch. · three or more — a native
disclosure, so N languages still cost one button. It opens without JavaScript because
is a disclosure element; the summary shows the language you are reading now. `hugo.Sites` lists every language site, including the current one, so the control renders identically on every page. */ -}} {{- if hugo.IsMultilingual -}} {{- $page := . -}} {{- $current := site.Language.Lang -}} {{- $entries := slice -}} {{- /* Resolve one entry per language: the translation of this page, or that language's home page when this page has no translation. */ -}} {{- range hugo.Sites -}} {{- $lang := .Language.Lang -}} {{- $url := .Home.RelPermalink -}} {{- with $page.Translations -}} {{- range . -}} {{- if eq .Language.Lang $lang }}{{ $url = .RelPermalink }}{{ end -}} {{- end -}} {{- end -}} {{- $entries = $entries | append (dict "lang" $lang "locale" .Language.Locale "label" .Language.Label "url" $url "current" (eq $lang $current)) -}} {{- end -}}
