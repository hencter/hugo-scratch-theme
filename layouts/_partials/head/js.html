{{- /* head/js.html — JavaScript pipeline. js.Build runs esbuild inside Hugo: it bundles the ES module graph, transpiles to the target, and injects the `@params` virtual module — which is how the search-index URL and the translated UI strings reach the browser without a second request or one data attribute per string.
