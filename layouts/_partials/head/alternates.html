{{- /* head/alternates.html — machine-discoverable versions of THIS page. a) Alternative output formats. Hugo exposes `.AlternativeOutputFormats`, which is every format in [outputs] that did NOT set notAlternative = true. Here that is RSS and the Markdown mirror (/index.md), so an agent can fetch the source instead of scraping HTML. b) hreflang. Every page declares at least its OWN language, and a page with translations declares the whole set plus `x-default`. The self-reference is not decoration: two kinds of page here have no translation to pair with, and both are legitimate rather than broken. · taxonomy terms whose zh and en names differ. `/tags/配置/` and `/en/tags/configuration/` are different terms, so Hugo has nothing to pair and `.AllTranslations` holds one entry; · pages generated by a content adapter, which creates pages in the default language only (see content/changelog/_content.gotmpl). Without the self-reference 40 of 258 rendered pages carried no hreflang at all, which is exactly the set a search engine is most likely to guess wrong. `x-default` points at the page in the language named by params.seo.xDefaultLang — guessing it from site.Languages order would break as soon as a language is added. */ -}} {{- $page := . -}} {{- range $page.AlternativeOutputFormats -}} {{ end -}} {{- if gt (len $page.AllTranslations) 1 -}} {{- range $page.AllTranslations -}} {{ end -}} {{- $seo := site.Params.seo | default dict -}} {{- $default := index $seo "xDefaultLang" | default site.Language.Lang -}} {{- range $page.AllTranslations -}} {{- if eq .Language.Lang $default -}} {{- end -}} {{- end -}} {{- else -}} {{- end -}}
